# Indago

Indago is a Python module for numerical optimization. It is developed at the Department of Fluid Mechanics and Computational Engineering of the Faculty of Engineering, University of Rijeka, by Stefan Ivić, Siniša Družeta, Luka Grbčić, and others.

Indago contains several modern methods for real fitness function optimization, with support for multiple objectives and constraints, and continuous/discrete real/integer variables, periodic variables, and categorical variables. 

Indago is developed mainly for in-house research and teaching purposes. Hopefully you would find it useful as well.

**Important: After every Indago update please check Release Notes since Indago methods and API can be significantly changed at any time.**

# Installation

You can install Indago from pip:

```
pip install indago
```

or update your existing Indago installation via:

```
pip install indago --upgrade
```
